# A Study of the Eight CISSP Domains

Short notes and personal reflection on the eight domains of the CISSP Common Body of Knowledge, written for a Cybersecurity Fundamentals / Ethical Hacking course.

| | |
|---|---|
| **Student** | Raphael Ndidi-Uboma |
| **Course** | Cybersecurity Fundamentals / Ethical Hacking |
| **Instructor** | Digital Eselsa |

## Contents

| # | Domain | Summary |
|---|--------|---------|
| 1 | [Security and Risk Management](domains/01-security-and-risk-management.md) | This is the foundation of CISSP and the domain closest to GRC. |
| 2 | [Asset Security](domains/02-asset-security.md) | Asset Security is about knowing what an organisation owns and protecting it throughout its life. |
| 3 | [Security Architecture and Engineering](domains/03-security-architecture-and-engineering.md) | This domain focuses on designing and building systems that are secure from the start rather than adding security later. |
| 4 | [Communication and Network Security](domains/04-communication-and-network-security.md) | This domain deals with protecting data as it moves across networks and protecting the network itself. |
| 5 | [Identity and Access Management (IAM)](domains/05-identity-and-access-management.md) | IAM makes sure the right people have the right access to the right resources at the right time. |
| 6 | [Security Assessment and Testing](domains/06-security-assessment-and-testing.md) | This domain is about checking whether security controls actually work. |
| 7 | [Security Operations](domains/07-security-operations.md) | Security Operations covers the daily work of keeping an organisation safe and responding when something goes wrong. |
| 8 | [Software Development Security](domains/08-software-development-security.md) | This domain focuses on building security into software throughout its life, from planning to retirement. |
