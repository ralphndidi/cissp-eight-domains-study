# Domain 6: Security Assessment and Testing

## Overview
This domain is about checking whether security controls actually work.

## Key Concepts
- Vulnerability assessments
- Penetration testing
- Security audits (internal, external or third party)
- Log reviews
- Security metrics
- Reporting findings to management so weaknesses can be fixed

## Real-World Example
Many organisations run yearly penetration tests and audits to satisfy regulators and customers, for example through SOC 2 or ISO 27001 certification. For GRC professionals this domain is very important because audit evidence proves that the organisation is following its own rules.

## Common Frameworks, Tools and Practices
- Nessus and OpenVAS for vulnerability scanning
- Nmap for network discovery
- Burp Suite and Metasploit for testing
- Audit checklists and control testing
