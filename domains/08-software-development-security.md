# Domain 8: Software Development Security

## Overview
This domain focuses on building security into software throughout its life, from planning to retirement.

## Key Concepts
- Software development life cycle (SDLC)
- Secure coding practices
- OWASP Top 10 web risks
- Code review and security testing
- Change control and DevSecOps
- Third-party library and software supply chain risks

## Real-World Example
A fintech company tests its mobile app and fixes weaknesses such as SQL injection before release, which is cheaper and safer than fixing them after a breach. Developers and security teams work together so that security is checked at every stage instead of only at the end.

## Common Frameworks, Tools and Practices
- SAST and DAST: SonarQube, OWASP ZAP
- Dependency scanners such as Snyk
- Git with code review
- Threat modelling methods such as STRIDE
