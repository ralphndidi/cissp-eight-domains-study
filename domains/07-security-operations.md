# Domain 7: Security Operations

## Overview
Security Operations covers the daily work of keeping an organisation safe and responding when something goes wrong.

## Key Concepts
- Monitoring and logging
- Incident response
- Digital forensics
- Patch and configuration management
- Change management
- Backup, disaster recovery and business continuity

## Real-World Example
A security operations centre (SOC) analyst notices many failed logins from a foreign country, investigates the alert, blocks the attacker and documents what happened. This domain also links to GRC, because incident reports and recovery plans must be documented and tested.

## Common Frameworks, Tools and Practices
- SIEM platforms: Splunk, Microsoft Sentinel
- Endpoint detection and response (EDR)
- SOAR automation
- Ticketing systems
- Regular backup and recovery testing
