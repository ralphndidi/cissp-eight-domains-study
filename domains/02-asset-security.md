# Domain 2: Asset Security

## Overview
Asset Security is about knowing what an organisation owns and protecting it throughout its life. Assets include data, devices, software and people.

## Key Concepts
- Identifying assets
- Classifying data (e.g. public, internal, confidential, restricted)
- Assigning data owners and custodians
- Setting retention periods
- Disposing of information safely when it is no longer needed
- Privacy protection

## Real-World Example
A hospital classifies patient records as highly sensitive, encrypts them, limits who can open them, and shreds old paper files securely. A bank does the same with customer account data.

## Common Frameworks, Tools and Practices
- Asset inventories and CMDBs
- Data loss prevention (DLP), e.g. Microsoft Purview
- Encryption
- Data masking
- Secure wiping or physical destruction of old drives
