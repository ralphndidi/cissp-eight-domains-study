# Domain 3: Security Architecture and Engineering

## Overview
This domain focuses on designing and building systems that are secure from the start rather than adding security later.

## Key Concepts
- Secure design principles: least privilege, defence in depth, fail-safe defaults, zero trust
- Security models
- Cryptography
- Secure hardware
- Cloud and virtualisation security
- Physical security of buildings and data centres

## Real-World Example
An online banking platform uses encrypted connections, layered controls, separated networks and a protected data centre so that one failure does not expose everything.

## Common Frameworks, Tools and Practices
- Encryption standards: AES and RSA
- Public key infrastructure (PKI) and TLS certificates
- Hardware security modules (HSMs)
- Trusted platform modules (TPMs)
- Cloud security architectures on AWS and Microsoft Azure
