# Domain 4: Communication and Network Security

## Overview
This domain deals with protecting data as it moves across networks and protecting the network itself.

## Key Concepts
- OSI and TCP/IP models
- Secure protocols: TLS, IPsec, SSH
- Network segmentation and VLANs
- Wireless security
- Common attacks: sniffing, spoofing, denial of service

## Real-World Example
Remote workers connect to the office through a VPN, and companies place payment systems on a separate network from guest Wi-Fi so that a breach in one area does not spread. These controls help organisations detect problems early and limit the damage of an attack.

## Common Frameworks, Tools and Practices
- Firewalls
- IDS/IPS: Snort, Suricata
- Wireshark for traffic analysis
- VPN gateways
- WPA3 for Wi-Fi
- Network access control (NAC)
