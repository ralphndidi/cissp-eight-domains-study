# Bonus: About ISC2

ISC2 (the International Information System Security Certification Consortium) is a global non-profit membership organisation founded in 1989. It is best known for creating and maintaining the CISSP certification, along with other credentials such as SSCP and Certified in Cybersecurity (CC).

ISC2:

- publishes the Common Body of Knowledge that defines the CISSP domains
- sets the Code of Ethics that members must follow
- requires continuing professional education so that certified people keep their skills current

In this way, ISC2 helps set a trusted global standard for cybersecurity professionals and supports the growth of the workforce.
